# Wangwang MVP 需求文档

## 1. 产品定位

Wangwang 是部署在 Cloudflare Workers 上的个人节点与 Mihomo 配置管理工具。核心流程为：

```text
导入节点源 -> 统一节点池 -> 创建配置 -> 选择节点与规则 -> 生成订阅链接
```

## 2. 用户与权限

- 仅支持一个管理员，不提供应用内账号系统。
- 管理后台位于 `/admin`，由 Cloudflare Access 保护。
- 订阅接口 `/s/*` 公开访问，依赖不可猜测且可轮换的订阅令牌。

## 3. MVP 功能

### 3.1 节点源

- 节点源只管理远程订阅 URL，不提供文本、文件或节点 URI 手动导入。
- 订阅内容支持 Mihomo YAML、Base64 URI 列表和普通 URI 列表；URI 支持 SS、VMess、VLESS、Trojan、Hysteria2、TUIC。
- Mihomo YAML 中其他合法代理类型按原始字段保留。
- URL 源支持手动刷新和定时刷新，默认每 6 小时，可选关闭、1、6、12、24 小时。
- 支持 ETag 和 Last-Modified 条件请求。
- 单个源最多 1 MiB；至少解析出一个有效节点才允许更新。
- 无效节点被跳过并记录警告；刷新失败保留上一次可用节点。
- 修改订阅地址时先异步验证，成功后替换地址和节点，失败时保留旧地址和旧节点。
- 停用节点源后停止刷新，并在配置生成时排除该来源的节点，但不删除已下载节点。

### 3.2 节点管理

- 全部节点进入统一节点池，通过连接参数指纹去重。
- 支持按名称、服务器、协议、来源和标签筛选。
- 支持重命名、启用/禁用、标签维护和批量启停。
- 支持在节点页面通过协议表单新增、编辑和删除单个手动节点。
- 手动节点支持 SS、VMess、VLESS、Trojan、Hysteria2、TUIC 及现有高级传输参数。
- 来源刷新后，相同指纹节点保留用户设置。
- 订阅节点的连接参数由节点源维护；手动节点的连接参数允许编辑。

### 3.3 配置与规则

- 一个配置可以引用多个节点源。
- 支持协议筛选、标签筛选和显式排除节点。
- 生成完整 Mihomo YAML，而不是仅生成代理列表。
- 默认基础设置：`mixed-port: 7890`、`mode: rule`、`allow-lan: false`、`ipv6: false`。
- 默认代理组：`节点选择`、`自动选择`、`故障转移`。
- 默认规则模块：广告拦截、私有网络直连、中国大陆直连、最终代理。
- 前三个模块可以启停和排序，最终 `MATCH` 固定在最后。
- DNS 默认启用 `fake-ip`，不提供原始 YAML 覆盖入口。

### 3.4 订阅链接

- 支持预览、复制和下载当前配置。
- 支持轮换订阅令牌；旧链接立即失效。
- 配置生成失败时继续提供上一版本。

### 3.5 管理界面

- 中文界面，桌面优先，兼容移动端。
- 页面包含概览、节点源、节点、配置列表和配置详情。
- 异步刷新与生成任务展示进行中、成功和失败状态。

## 4. 非目标

MVP 不包含多用户、流量统计、链式代理、模板市场、Sing-box 输出、远程规则集、自定义 YAML、可视化规则编辑和在线测速。

## 5. 默认容量

- 节点源：20 个。
- 全局节点：2000 个。
- 配置：20 个。
- 单配置节点：1000 个。
- 单次输入和单份生成配置：1 MiB。

## 6. 验收标准

1. 管理员可以添加、编辑、停用和刷新远程订阅，并看到解析结果和警告。
2. 管理员可以修改节点名称、标签和启停状态。
3. 管理员可以在节点页面新增、编辑和删除单个手动节点。
4. 管理员可以创建配置、选择来源和规则并生成 Mihomo YAML。
5. Mihomo 可以通过订阅链接获取并加载生成配置。
6. 令牌轮换后旧链接返回 404，新链接正常工作。
7. 定时刷新成功后相关配置自动更新；失败时旧配置仍可使用。
8. 未通过 Cloudflare Access 的请求无法访问 `/admin`，但有效订阅链接不需要登录。
